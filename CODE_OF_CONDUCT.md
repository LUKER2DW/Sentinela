# Code of conduct

Sentinela follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep discussions about the work, and
never post other people's camera footage, addresses or personal data.

Report unacceptable behaviour privately to the maintainer through the
repository's **Security** tab (*Report a vulnerability*) or by e-mail to the
address on the maintainer's GitHub profile. Reports are handled
confidentially.
